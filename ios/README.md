# ios/

Нативний клієнт **Swift / SwiftUI**. Тут ваша основна розробка прототипу і демо.

## Призначення

- Один шаблон екрана (текст + 1–3 кнопки + смуга 103).
- Читання графа з `../protocol/`.
- Системний TTS (UA/EN), QR/камера, GNSS, локальний журнал.
- Пізніше — on-device моделі (Core ML), якщо знадобляться; **не** для тріажу.

## Чого тут немає на старті

- Xcode-проєкт (додасте, коли почнеться код).
- Бекенд, акаунт, синхронізація з ЕСОЗ.

## Залежність

Єдине джерело кроків — `protocol/`. Якщо фраза неправильна — правити протокол і docs, не хардкодити в View.
