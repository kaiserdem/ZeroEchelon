# Handed to medic (guide end)

## Description

Явний кінець гострого гайду після передачі звіту: Form/Give → **Передав медику** → підтвердження → Home з вибором лишити журнал (24/48) або стерти.

## Requirements

- [x] Кнопка `Передав медику` на Form і на Give
- [x] Вузол `Handed`: коротке підтвердження + два вибори
- [x] `Лишити для 24/48` → Home, журнал і нагадування лишаються
- [x] `Стерти журнал` → очищення події + скасування нагадувань → Home
- [x] iOS + web; unit-тест на keep і erase

## Acceptance Criteria

1. З Form можна закрити гайд без «застрягання» на звіті.
2. Після keep на Home видно «Остання подія».
3. Після erase на Home блока останньої події немає.

## Notes

Не змінює медичний зміст гілок C–J. Erase з Form (окремо) лишається.
