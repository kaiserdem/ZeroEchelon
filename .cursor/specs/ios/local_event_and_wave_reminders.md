# Local event journal + wave reminders (24/48)

## Description

Одна локальна подія на пристрої (не історія багатьох інцидентів) і локальні нагадування `UNUserNotificationCenter` на 24 і 48 год для чек-листа другої хвилі (I0). Без хмари / APNs.

## Requirements

- [x] Модель однієї події: `eventId`, `startedAt`, роль, тип, локація, кроки — зберігається локально (файл), не синхронізується
- [x] Старт події: Home → `incident` фіксує `startedAt`
- [x] Після першого досягнення `Form` — запит дозволу (якщо треба) і планування двох локальних сповіщень: +24 год і +48 год від `startedAt`
- [x] Тап по сповіщенню відкриває `I0` (чек-лист після події)
- [x] Erase (`Erase` → `next`) стирає журнал, скасовує обидва нагадування, повертає на Home
- [x] Автоочищення: якщо з `startedAt` минуло понад 48 год — журнал і нагадування прибираються при запуску
- [x] Відновлення при запуску: гідратація полів чернетки в engine; екран старту — Home (не середина графа)
- [x] Немає списку минулих подій / хмарного пушу (явно out of scope)

## Acceptance Criteria

1. Після гострого шляху до Form і дозволу на сповіщення в системі з’являються два заплановані локальні запити (`wave-24`, `wave-48`).
2. Після Erase у центрі сповіщень немає цих запитів, локальний файл порожній.
3. Unit-тести покривають persist/load/clear і побудову fire dates без реальної доставки.
