# Zero Echelon

Офлайн-алгоритм порятунку для перших хвилин після масової травми. Продукт розрахований на нетренованого цивільного свідка: він веде людину голосом і на екрані, без мережі, і в кожен момент говорить одну конкретну дію замість переліку варіантів.

## Що тут є

У [`docs/`](docs/README.md) — документація (почніть з індексу). Первинні дослідження — у [`docs/research/`](docs/research/).

- [`protocol/`](protocol/README.md) — спільне ядро алгоритму (дані / graph.json)
- [`ZeroEchelon/`](ZeroEchelon/README.md) — Xcode SwiftUI-додаток + unit-тести рушія
- [`web/`](web/README.md) — майбутній PWA для QR
- [`tools/`](tools/README.md) — валідатори (пізніше)

Деталі поділу: [`docs/13-структура-репозиторію.md`](docs/13-структура-репозиторію.md).

## Чого тут немає

Документація фіксує зміст рішень; UI і код — у `ZeroEchelon/`. Проєкт не обіцяє юридичного захисту на кшталт Good Samaritan.
