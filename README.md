# Line 24

Офлайн-додаток для цивільного **безпечного свідка** у перші хвилини після події (вибух, ДТП, пожежа, завал тощо). Великі кнопки і голос, **без мережі**, **одна дія на екран**. Після зворотного звʼязку поліції / ДСНС активний шлях **не** дає команд лікування.

Репозиторій / робоча назва ядра: **Zero Echelon**. На екрані телефону бренд — **Line 24**.

**Режим за замовчуванням:** `civilianSafeMode` у `protocol/.../engine-rules.json`. Нотатка: [`docs/stakeholder/півот-цивільний-безпечний.md`](docs/stakeholder/півот-цивільний-безпечний.md).

## Що робить додаток

На головному екрані **два** входи:

| Кнопка | Навіщо |
| --- | --- |
| **Щось сталось зараз** | Дисклеймер → місце → тип події → безпека сцени → **112** → Safe-civil → звіт / QR |
| **Чек-лист після події** | «Друга хвиля»: короткі питання про відкладені загрози → знову 112 / лікарня |

Вхід «Симптоми / щоденна допомога» і дерева лікування (сортування, тиск на рану тощо) **сховані** в графі; повертаються прапорцем `civilianSafeMode.enabled: false`.

Після гострої події додаток:

- тримає **локальний журнал однієї події** (не хмара);
- нагадує через **24 і 48 годин** пройти чек-лист знову;
- на Home показує **останню подію** і дає відкрити звіт;
- формує чернетку для диспетчера / QR для служб на місці.

**112** завжди на екрані; **101** — на вето небезпечної зони. Номера **103** немає. Продукт **не** замінює бригаду і **не** обіцяє Good Samaritan.

### Швидкий старт

- **iOS:** відкрити `ZeroEchelon/ZeroEchelon.xcodeproj` у Xcode, схема `ZeroEchelon`.
- **Web-демо:** `cd web && npm install && npm run dev`.

## Чого тут немає

- Хмари, логіну, ЕСОЗ, пушу з сервера.
- Службових ролей (лише свідок / постраждалий).
- Скріншотів у README поки немає — UI ще каркас; коли зафіксуємо візуал, можна додати 1–2 кадри Home і звіту.
