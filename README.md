# Line 24

Офлайн-алгоритм цивільного порятунку для перших хвилин після події (вибух, ДТП, пожежа, завал тощо). Розрахований на нетренованого свідка або постраждалого: веде голосом і великими кнопками, **без мережі**, і в кожен момент дає **одну конкретну дію**, а не меню протоколів.

Репозиторій / робоча назва ядра: **Zero Echelon**. На екрані телефону бренд — **Line 24**.

## Що робить додаток

На головному екрані три входи:

| Кнопка | Навіщо |
| --- | --- |
| **Щось сталось зараз** | Гострий шлях: дисклеймер → місце → тип події → безпека сцени → допомога → звіт для 103 / медика |
| **Симптоми / щоденна допомога** | Поза масовою травмою: інсульт, отруєння, анафілаксія тощо (без повного S0) |
| **Чек-лист після події** | «Друга хвиля»: короткі питання про відкладені загрози |

Після гострої події додаток:

- тримає **локальний журнал однієї події** (не хмара, не історія багатьох інцидентів);
- нагадує через **24 і 48 годин** пройти чек-лист знову (кров у кашлі, темна сеча, голова/блювання, біль у животі);
- на Home показує **останню подію** і дає відкрити звіт для служб;
- формує чернетку для диспетчера / QR для медика на місці.

103 (і 101 на вето-екранах) доступні майже завжди. Продукт **не** є заміною бригади і **не** обіцяє юридичного захисту на кшталт Good Samaritan.

### Швидкий старт

- **iOS:** відкрити `ZeroEchelon/ZeroEchelon.xcodeproj` у Xcode, схема `ZeroEchelon`.
- **Web-демо:** `cd web && npm install && npm run dev`.

## Чого тут немає

- Хмари, логіну, ЕСОЗ, пушу з сервера.
- Службових ролей (лише свідок / постраждалий).
- Скріншотів у README поки немає — UI ще каркас; коли зафіксуємо візуал, можна додати 1–2 кадри Home і звіту.
