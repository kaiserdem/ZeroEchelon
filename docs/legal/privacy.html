Політика конфіденційності

Останнє оновлення: 14 вересня 2026

Ця політика описує, як застосунок Line 24 (робоча назва ядра — Zero Echelon) обробляє дані. Коротко: журнал події зберігається лише на вашому пристрої; ми не ведемо облікових записів і не надсилаємо медичні дані на наші сервери.

1. Хто ми

Видавець застосунку Line 24. Звʼязок: через сторінку підтримки або GitHub Issues.

2. Які дані обробляються

  • Локальний журнал однієї події (тип інциденту, роль, чернетка місця/звіту, мітки часу, за потреби лічильники SALT / час турнікета) — лише у сховищі пристрою.
  • Локальні нагадування через 24 і 48 годин (системні нотифікації на пристрої).
  • Мікрофон і розпізнавання мови — лише якщо ви самі вмикаєте диктовку адреси; аудіо не зберігається нами і не надсилається на наші сервери. Обробка йде через системні API Apple на пристрої.
  • QR / текст звіту — формується на пристрої; передача іншій особі лише з вашої ініціативи.

3. Чого ми не робимо

  • Не створюємо акаунти й не вимагаємо входу.
  • Не збираємо аналітику з корисним навантаженням про здоровʼя чи інцидент.
  • Не продаємо й не передаємо персональні дані третім сторонам для реклами.
  • Не підключаємося до ЕСОЗ / центральних медичних реєстрів.

4. Зберігання і видалення

Дані журналу лишаються на пристрої, доки ви не оберете стирання (наприклад, після «Передав медику» → «Стерти журнал») або не видалите застосунок. Рекомендуємо стирати журнал після передачі службам.

5. Дозволи iOS

  • Мікрофон — для диктовки полів адреси.
  • Розпізнавання мови — те саме.
  • Сповіщення — для локальних нагадувань 24/48 год (якщо ви дозволите).

6. Діти

Застосунок не призначений для дітей як окрема аудиторія; ним може користуватися будь-хто в надзвичайній ситуації. Ми свідомо не збираємо дані для профілювання неповнолітніх.

7. Зміни

Оновлення цієї політики публікуватимуться на цій сторінці з новою датою.

8. Контакт

Питання щодо приватності: github.com/kaiserdem/ZeroEchelon/issues (тема: Privacy).
