# 06 — Схема даних протоколу

> **Статус: чернетка.** Документа ще не написано. Нижче зафіксовано призначення й план розділів, щоб залежності від нього були видимі. Не покладайтеся на цей файл як на джерело істини.

Машиночитаний формат графа рішень і мапінг на FHIR. Документ описує, як блок-схеми з [04 — Блок-схеми](04-блок-схеми.md) записуються у структуру даних, у якій кожен вузол несе посилання на редакцію протоколу з [02 — Реєстр протоколів](02-реєстр-протоколів.md).

---

## План розділів

1. Модель вузла: ідентифікатор, тип, текст UA/EN, джерело з редакцією, умови переходу.
2. Модель графа: переходи, гілки, точки вето, вхідні та термінальні вузли.
3. Правила валідації графа — недосяжні вузли, цикли, вузли без джерела.
4. Мапінг на FHIR для передачі до ЕСОЗ.
5. Версіонування схеми та процедура міграції при зміні редакції протоколу.
