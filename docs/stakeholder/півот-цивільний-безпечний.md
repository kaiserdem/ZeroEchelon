# Півот: цивільний безпечний шлях (після зустрічі з поліцією / ДСНС)

**Дата:** 2026-10-04. Не канон протоколів — операційна нотатка. Канон: `docs/01`–`13`, право — `docs/10`.  
Партнерські аркуші в цій папці мають відповідати **активному** SKU нижче, а не архівним деревам лікування.

## Висновок зустрічі

1. Якщо цивільний почав допомагати і людина померла — можливе кримінальне провадження; давати команди «як лікувати» цивільному небезпечно.
2. Після влучання / під час тривоги служби можуть **не заходити** в зону через повторний удар.

## Рішення продукту

**SKU «безпечний свідок» (увімкнено зараз):**

| Лишаємо | Ховаємо |
| --- | --- |
| Виклик **112** | Сортування (SALT) як команди «куди йти» |
| Вето безпеки сцени (A*, Out / Out-trapped) і **101** | Кровотеча, дихання, груди, інші кроки лікування |
| Місце, тип події, роль | PFA як протокол «допомоги» |
| Звіт / QR для служб | Щоденний медичний модуль J (третя кнопка Home) |
| Чек-лист після події (24/48 год) | |

**Головний екран зараз — дві кнопки:** «Щось сталось зараз» · «Чек-лист після події». Модуль «Симптоми / щоденна допомога» прихований.

Після Call користувач бачить екран **Safe-civil** (не лікувати за додатком; не заходити в зону після удару) → звіт для служб.

Технічно: `engine-rules.json` → `civilianSafeMode.enabled: true`. Дерева B–G/J **не видалені** з графа — повертаються прапорцем `false`.

## Як повернути лікування

1. У `protocol/graphs/zero-echelon-core/engine-rules.json` і копії в iOS Resources: `"enabled": false`.
2. Rebuild iOS / reload web.

## Для партнерів (коротко)

Line 24 у активному режимі — **безпечний свідок**, не медичний тренер: виклик, безпека сцени, місце, звіт, чек-лист після події. Команд «тисни на рану», «іди до мовчазного» тощо додаток цивільному **не дає**.
