# Півот: цивільний безпечний шлях (після зустрічі з поліцією / ДСНС)

**Дата:** 2026-10-04. Не канон протоколів — операційна нотатка. Канон: `docs/01`–`13`, право — `docs/10`.  
Партнерські аркуші в цій папці мають відповідати **активному** SKU нижче, а не архівним деревам лікування.

## Висновок зустрічі

1. Якщо цивільний почав допомагати і людина померла — можливе кримінальне провадження; давати команди «як лікувати» цивільному небезпечно.
2. Після влучання / під час тривоги служби можуть **не заходити** в зону через повторний удар.

## Рішення продукту

**SKU «цивільний свідок» (увімкнено зараз):**

| Лишаємо | Ховаємо / не даємо |
| --- | --- |
| Виклик **112** | Алгоритми лікування і рятування |
| Фіксація місця, типу, видимих ознак без наближення | Сортування (SALT) як команди «куди йти» |
| Звіт / QR для служб | Кровотеча, дихання, груди, інші кроки лікування |
| Чек-лист після події (24/48 год) | PFA як протокол «допомоги» |
| **101** на екранах небезпечної зони | Щоденний медичний модуль J; накази «відійдіть», «увімкніть», «вимкніть» |

**Головний екран зараз — дві кнопки:** «Щось сталось зараз» · «Чек-лист після події».

Після Call — **Safe-civil** (фіксація і передача службам; без фізичних вказівок програми) → звіт.

Технічно: `engine-rules.json` → `civilianSafeMode.enabled: true`. Дерева B–G/J **не видалені** з графа.

Офіційний опис для бланка: [укрноіві-функціональність.md](укрноіві-функціональність.md).

## Як повернути лікування

1. У `protocol/graphs/zero-echelon-core/engine-rules.json` і копії в iOS Resources: `"enabled": false`.
2. Rebuild iOS / reload web.

## Для партнерів (коротко)

Line 24 у активному режимі — **цивільний свідок**, інформаційний і комунікаційний контур: виклик, фіксація видимого без наближення, звіт. Команд фізичного втручання додаток цивільному **не дає**.
