# 5. Коротко для учасників групи

Одна сторінка: хто ви, що робите, що здаєте. Деталі — у розділах 3 і 4 тетрадки.

Додаток веде звичайну людину в перші хвилини. Службовець читає той самий цивільний екран — окремого режиму «для поліції / ДСНС / лікаря» немає.

Перевіряємо дві речі:

1. чи налякана людина без підготовки робить **правильну першу дію**;  
2. чи служби за ~20 секунд розуміють екран / QR **без** пояснень розробника.

Екстрений номер: **112**. На екранах небезпечної зони — **101**.

## 5.2. Що тестувати

**Крок 1. За стіл.** Служби кажуть «екран нам підходить» — перш ніж кликати людей.

**Крок 2. Люди.** Звичайні люди без підготовки. Спостерігач мовчить.

**Чотири майданчики:** поїзд / перон; автобус або авто; село; місто.

**Дванадцять сцен:**

1. Кров із руки чи ноги → тиск + 112  
2. Крик і мовчазний → спочатку до мовчазного  
3. Рана в грудях → не заклеюй  
4. Людина під уламком → не знімай  
5. Підозрілий предмет → відійди + 101  
6. Після вибуху не дихає → іди за екраном  
7. Важка алергія → 112, не таблетка  
8. Наступного дня кров у кашлі → знову 112  
9. Поїзд / перон → 112, не проти натовпу  
10. Автобус або авто горить → вийти  
11. Село без звʼязку → назвати місце словами  
12. Міський підʼїзд, дим → відійти  

**Крок 3.** Патруль, ДСНС, ЕМД читають звіт без розробника.

## 5.3. Який звіт хочемо

1. Після столу — усі 25 кажуть «так» або що змінити в тексті.  
2. Після людей — аркуш на кожен прогін + таблиця по сценах.  
3. Після служб — зрозуміли екран за ~20 с: так / ні.

**Позитив:** усі 25 погоджують; людина тисне на рану, відходить від небезпеки, іде спочатку до мовчазного; служби читають звіт самі.
