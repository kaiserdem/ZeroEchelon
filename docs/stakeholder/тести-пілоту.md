# Тести пілоту — Line 24

**Мета:** перевірити не «чи правильна медицина» (це вже в протоколах), а чи **послідовність і мова** працюють для наляканої нетренованої людини, і чи службам зрозумілий екран зустрічі.  
**Дата:** 17.09.2026.  
**Опора:** `docs/11` + узгодження міжвідомчої групи.

Три кола: спочатку папір, потім зал, потім зустріч зі службами. **Не** одразу сирена в підʼїзді.

SOS-маяк і ультразвук **не** класти в цю програму, поки ядро не пройшло кола 1–2.

Екстрений номер у продуктах тестів: **112** (вето-зона — **101**).

---

## Коло 1. За стіл (група без цивільних)

**Мета:** служби кажуть «цей екран нам підходить» **до** того, як лякати людей.

| Перевірка | Хто веде | Критерій «ок» |
| --- | --- | --- |
| Звіт (де / що / скільки людей / хто недосяжний / коли джгут) читається за ~20 с | ЕМД + ДСНС + патруль | Усі троє знаходять поля без підказки розробника |
| Номери і фрази **112** / **101** | Диспетчери | Текст — те, що реально хочуть почути |
| Завал / міна: «не звільняй, не заходь» | Сапери / ДСНС | Як учить служба, не «герой у кіно» |
| Немає дебрифінгу («розкажи, що відчуваєш») | Психологи | Формулювань дебрифінгу немає |
| Дисклеймер; довідник vs медичний виріб | Юрист + МОЗ (+ Держлікслужба за потреби) | Одна рамка на пілот, без змішування |
| QR / листок «зі слів супроводжуючого», без фантазій про ЕСОЗ | Лікарні | Можна прийняти в роботу |

**Вихід кола 1:** протокол узгодження екрана звіту + список правок мови (якщо є). Без цього коло 2 не стартує.

## Коло 2. Симуляція з цивільними (головний тест)

**Учасники:** не менше **~24 цивільних без підготовки** на майданчик.  
**Ролі в додатку:** свідок і постраждалий (самодопомога).  
**Службовець:** спостерігає, **не** підказує, доки не спрацює критерій зупинки.

**Майданчики (два контрасти):**

1. Щільна забудова — підʼїзд, обмежений вихід.  
2. Віддалена локація / глуха громада — слабший звʼязок, місце без QR або з ручним введенням.

**Муляжі,** не чужа кров на сторонніх.

### Сценарії (кожен — щонайменше кілька прогонів: UA / EN, свідок / постраждалий де доречно)

| № | Сценарій | Що вважаємо успіхом |
| --- | --- | --- |
| 1 | Одна кровотеча кінцівки, джгута немає | Тиск на рану + доступ до **112** |
| 2 | Двоє кричать, один мовчить і нерухомий | Спочатку йде до **мовчазного** |
| 3 | Відкрита рана грудей; поруч плівка і скотч | **Не** заклеює |
| 4 | Людина під плитою просить зняти вагу | **Не** звільняє |
| 5 | Підозрілий предмет і поранений за ним | Відходить + **101** |
| 6 | Непритомний після вибуху; поруч кровотеча | Без фатальних відхилень; пріоритет за алгоритмом |
| 7 | Укус оси, свист у диханні, адреналіну немає | **112**, не «таблетка від алергії» |
| 8 | «Минуло 24 години», кров у кашлі | **112**, не «поспостерігати» |

### Окремо (не замість сценаріїв 1–8)

| Умова | Навіщо |
| --- | --- |
| Темрява, брудні / тремтячі руки, сирена в навушниках | Чи попадає в кнопку |
| Без мережі; холодний підвал; батарея | Чи живе додаток (цифру % **не** обіцяти, поки не заміряли) |
| Українська і англійська | Паритет мови |
| Сліпий / слабкий зір / одна рука | Доступність |

### Критерій зупинки спостерігача

Учасник збирається: увійти в «завал», герметизувати груди, зробити джгут із ременя, «звільнити» кінцівку, або ігнорує UXO.

### Що міряти (форма спостерігача — обовʼязкова)

- Час від відкриття до першої **правильної** дії (112 або тиск — залежно від сценарію).  
- Час до відходу при UXO (сценарій 5).  
- Чи пішов до мовчазного раніше за кричущого (сценарій 2).  
- Кількість фатальних відхилень: герметизація грудей, ремінь, звільнення, вхід у завал, дебрифінг.  
- Відмова від ведення: закрив додаток / «я сам знаю».  
- Чи зачитав диспетчеру місце свого рівня точності.  
- Різниця свідок vs постраждалий: чи не зʼявилося сортування чужих у самодопомозі.

### Успіх / провал кола 2

**Успіх:** після правки текстів у сценаріях 3–5 більше ніхто не робить фатальну помилку; у сценарії 2 більшість іде до нерухомого.  
**Провал:** та сама фатальна помилка повторюється після зміни скрипту; або рецензент визнає ключове рішення неприйнятним без заміни.

### Як фіксувати

| Що | Навіщо |
| --- | --- |
| **Форма спостерігача** (основа) | Однакова на кожен прогін — інакше не звести таблицю |
| **Відео** екрана + рук (за згодою) | Перевірити час і факт помилки; обличчя — лише з окремого дозволу |
| **Фото** | Рідко: кадр звіту / QR в кінці |
| **Звід** | Таблиця по сценаріях + рішення групи, що змінити в текстах |

До старту: згода на зйомку, хто зберігає файли, термін видалення, заборона викладати в соцмережі.
