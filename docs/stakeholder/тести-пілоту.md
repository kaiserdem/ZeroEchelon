# Тести пілоту — Line 24

**Активний продукт = безпечний режим** (`civilianSafeMode`). Див. [півот-цивільний-безпечний.md](півот-цивільний-безпечний.md).

Перевіряємо не «чи правильна медицина лікування» (команд лікування цивільному зараз немає), а чи **мова і порядок екранів** працюють для наляканої людини без підготовки: виклик **112**, відхід від небезпеки, місце, звіт — і чи службам зрозумілий звіт.

Три кроки: спочатку за стіл, потім люди, потім служби на місці. **Не** одразу сирена в підʼїзді.

SOS-маяк і ультразвук у цю програму **не** кладемо.

Екстрений номер: **112** (небезпечна зона — **101**).

---

## Крок 1. За стіл (без цивільних)

Мета: служби кажуть «цей екран нам підходить» **до** тестів з людьми.

| Перевірка | Хто | Ок |
| --- | --- | --- |
| Звіт читається за ~20 с | ЕМД + ДСНС + патруль | Знаходять поля без підказки |
| Фрази **112** / **101** | Диспетчер 112 (+ ДСНС для 101) | Текст — те, що хочуть почути |
| Завал / підозрілий предмет | Сапер / ДСНС | Людину вчать відійти |
| Немає команд лікування | МОЗ + юрист + поліція | Немає «тисни на рану» тощо |
| Немає «розкажи, що відчуваєш» | Психолог | Таких фраз немає |
| Дисклеймер; safe mode | Юрист + МОЗ | Одне рішення на пілот |
| Листок / звіт для служб | Лікарня / сімейний лікар | Можна прийняти |

Без протоколу цього кроку людей не кличемо.

---

## Крок 2. Люди (головний тест)

Звичайні люди без підготовки. Спостерігач мовчить, доки людина не збирається зробити небезпечне.

**Чотири майданчики**

1. Поїзд / перон.  
2. Автобус або авто.  
3. Село / громада — слабкий звʼязок.  
4. Місто — підʼїзд.

Муляжі, не чужа кров. **Не** оцінюємо «чи правильно тиснула на рану» — додаток цього не веде.

### Дванадцять сцен

| № | Сцена | Успіх (safe mode) |
| --- | --- | --- |
| 1 | Кров із руки чи ноги | **112** + звіт; не шукає «лікування» в додатку |
| 2 | Крик і мовчазний | **112**, місце, звіт |
| 3 | Рана в грудях | **112**; не чекає команди лікування |
| 4 | Людина під уламком | Не знімає; відходить; **112** |
| 5 | Підозрілий предмет | Відходить + **101** |
| 6 | Після вибуху | Safe-civil: не заходить у зону; **112**; звіт |
| 7 | Важка подія / алергія | **112** і звіт |
| 8 | Наступного дня кров у кашлі | Знову **112** (чек-лист) |
| 9 | Поїзд / перон | **112**, не проти натовпу |
| 10 | Автобус або авто горить | Вийти |
| 11 | Село без звʼязку | Назвати місце словами |
| 12 | Міський підʼїзд, дим | Відійти; **101** / **112** |

Окремо (не замість сцен): темрява, брудні руки, сирена, без інтернету, українська / англійська, одна рука / слабкий зір.

**Стоп:** людина збирається полізти в завал, «звільнити» уламок або підійти до підозрілого предмета.

**На кожен прогін** — один аркуш спостерігача (час до правильної дії, 112/101, помилки, чи закрив додаток).

**Успіх:** група з 25 каже «так»; після правки текстів ніхто не лізе в небезпеку і не чекає від додатка команд лікування; більшість доходить до **112** і звіту.

## Крок 3. Служби на місці

Патруль, ДСНС, ЕМД читають екран / QR **без** розробника.

Час доїзду можна записати для себе — це не оцінка додатка.

## Порядок

1. Крок 1 → протокол.  
2. Етика + згоди.

4. Крок 3.  
5. Зведена таблиця → оновлення партнерських текстів / канону за потреби.
