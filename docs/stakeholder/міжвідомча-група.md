# Міжвідомча робоча група — Line 24

**Призначення:** узгодити пілот і тести застосунку.  
**Не призначення:** переписувати медицину з голосу відомств — протоколи вже зафіксовані.  
**Дата:** 17.09.2026.

---

## Навіщо група

Група потрібна **не** щоб «перевірити, чи правильна медицина» — це вже в протоколах.  
Вона потрібна, щоб перевірити:

1. чи **цивільний у паніці** робить правильну **першу** дію;
2. чи **службам** зрозумілий екран / QR, з яким їх зустрічають.

Додаток веде **свідка** (або постраждалого), **не** поліцейського і **не** лікаря.

На першому засіданні проговорити вголос:

> У додатку **немає** режиму «для поліції / ДСНС / лікаря». Службовець, який відкрив QR, іде **тим самим цивільним шляхом**.

---

## Склад

### A. Кістяк (уже в контурі)

| Учасник | Роль у групі / на тесті |
| --- | --- |
| ДСНС | Сцена: вогонь, дим, завал, UXO; формулювання «відійди / не чіпай» |
| Національна поліція | Чи звіт і місце зрозумілі службі на місці |
| Патрульна поліція | Те саме на рівні першого контакту |
| Екстрена медична допомога (ЕМД) | Передача постраждалого; час джгута; чи екран корисний бригаді |
| Заклади ОЗ: первинний рівень | Чи листок/QR можна прийняти «зі слів супроводжуючого» |
| Заклади ОЗ: вторинний / третинний | Те саме для приймального / травми |
| Психологи | Мова без дебрифінгу; стрес симуляції; критерії зупинки за станом учасника |

### B. Обовʼязково додати (інакше пілот кульгає)

| Кого | Навіщо |
| --- | --- |
| **Диспетчери 112** (і окремо **101**) | Чи текст на екрані — те, що вони хочуть почути. Не плутати з бригадою на місці |
| **Сапери / вибухотехніки ДСНС** | Екран «відійди, не чіпай» — їхнє вето, не медиків |
| **МОЗ** | Рамка: довідник чи медичний виріб. Без цього пілот юридично сірий |
| **Держлікслужба** | Якщо виріб — їхній контур допуску |
| **Кафедра / лікар медицини катастроф** | Рецензія спірних рішень (груди, завал, один непритомний) |
| **Юрист** (медправо + персональні дані) | Немає Good Samaritan; нуль медданих у хмару; згоди на зйомку |
| **Комісія з етики** | Симуляції на людях, стрес, звук вибуху / сирени |
| **Люди з інвалідністю** (зір, слух, моторика) | Не лише «гігантська кнопка для здорових рук» |
| **Червоний Хрест України** | Рецензент мови допомоги (не заміна ERC) |
| **Носій англійської** | Іноземець у вагоні / волонтер — перевірка EN |
| **КОГА / замовник пілоту** | Майданчики, допуск, страхування |
| **Представник цивільних** (не службовець) | Інакше група тестує себе, а не користувача |

### C. Не обовʼязково в постійний склад

СБУ, Міноборони, Мінцифри — лише якщо **самі** просять. Додаток не для них.

## Ролі на тесті (хто що робить)

| Хто | Що робить |
| --- | --- |
| **Цивільний** | Натискає. Єдиний «користувач» додатка |
| **Медик катастроф** | Критерій зупинки: заклеїти груди, ремінь-джгут, завал, міна |
| **ДСНС** | Сцена вогонь / завал / UXO |
| **Поліція / патруль** | Не «чи є режим для нас», а чи звіт і місце зрозумілі |
| **ЕМД** | Передача; час джгута |
| **Психолог** | Мова, стрес; заборона розпитувати «що відчуваєш» |
| **Лікарня** | Чи листок/QR можна взяти в роботу |
| **Юрист / етика** | Допуск людей, страхування, згода на зйомку |
| **Диспетчер 112/101** | Оцінює текст виклику (коло 1 і за потреби коло 3) |

Одне речення для першого засідання:

> Група затверджує сценарії й спостерігає; додаток тестують звичайні люди; медицину не переписуємо з голосу відомства — лише мову екрана і передачу на місці.

---

## Порядок роботи групи

1. Затвердити склад і ролі (цей документ).  
2. Коло тестів 1 (за стіл) — див. документ «Тести».  
3. Коло 2 (цивільні) — лише після кола 1 і етики/страхування.  
4. Коло 3 (служби на місці).  
5. Зведена таблиця результатів → правки текстів у техкоманди → повтор критичних сценаріїв.

**Екстрений номер у продукті: 112** (на вето-екранах — **101**).
