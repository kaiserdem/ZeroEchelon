# Line 24 — що вже в додатку і що пізніше

**Для передачі партнерам.** Не канон протоколів. Канон: `docs/01`–`13`.  
**Активний SKU:** [півот-цивільний-безпечний.md](півот-цивільний-безпечний.md) — безпечний свідок, без команд лікування.

**Готовий PDF:** [line-24-shcho-vzhe-ye.pdf](line-24-shcho-vzhe-ye.pdf) (може відставати від цього аркуша — друкуйте з HTML).

Офлайн-додаток для цивільного **безпечного свідка**. Бренд на екрані — **Line 24**. Великі кнопки і голос: виклик **112**, перевірка небезпеки сцени, місце, короткий звіт для служб, чек-лист після події. **Не** веде медичні кроки лікування. Не замінює бригаду.

Те, що в концепції називали «блоком 2» (голос, місце, перевірка через 24 і 48 годин), **вже є** у безпечному шляху. Команди лікування (тиск на рану, сортування тощо) у активному режимі **не показуються**.

## Тексти, які вже є (без лікування)

Голос — наказовий лад, одна дія. У безпечному режимі акцент на виклик, відхід від небезпеки, місце і звіт — **не** на лікування рани.

Приклади з активного шляху / вето:

- «Викличте 112.» / кнопка «Викликати 112», `tel:112`.
- «Не чіпайте предмет і уламки. Не смикайте. Не звільняйте.»
- Після Call (Safe-civil): не лікувати за додатком; не заходити в зону після удару.
- На небезпечній зоні — **101**, відійти.

Чек-лист через 24 і 48 годин (будь-яке «так» → 112 або лікарня; «ні» **не** означає «все добре»):

1. Є кров у кашлі, задишка, біль у грудях, сині губи?
2. Сеча темна, як чай? Сечі стало менше? Кінцівка пухне і болить сильніше?
3. Головний біль не минає або наростає? Було блювання? Сонливість, плутана мова?
4. Біль у животі? Кров у блювоті або в стільці?

Повний список фраз: `docs/07`. Джерела ознак: CDC, ISN, NICE — `docs/09`.

## Пізніше — після пілоту ядра

Не блокує запуск безпечного шляху. Окремі рішення, договори або дослідження.

| Коли | Що |
| --- | --- |
| Найближче до ядра | Більші кнопки, чорний екран OLED, вібрація в темряві; тест під сирени; замір батареї в холоді |
| Окремий шар, не гострий шлях | Картки: вода, блекаут, пожежа в побуті |
| Окремий шар | Стрічка новин області (лише завантаження, нічого не відправляти) |
| Окремий шар | Маршрути вихідного дня, мапа укриттів громади |
| Партнери + юристи | Знижки / ваучери / кешбек |
| Окреме ТЗ | SOS-спалах кодом Морзе |
| Не в пілот без дослідження | Ультразвук «для собак» |
| Лише окремим рішенням | Повернення команд лікування (`civilianSafeMode` → `false`) — після юридичного / службового «так» |

Головний екран **не** замінювати кнопками «пожежа / кровотеча / SOS»: тоді людина в паніці пропускає виклик 112, місце і перевірку небезпеки. Третьої медичної кнопки зараз немає свідомо.

## Для слайдів назовні

Можна казати: додаток допомагає цивільному **безпечно викликати допомогу**, перевірити небезпеку сцени, зафіксувати місце і передати короткий звіт службам; після події — чек-лист 24/48. Орієнтири протоколів у каноні (SALT, TECC Active Bystander, ERC, Stop the Bleed тощо) — у `docs/11`, але **активний цивільний шлях їх як команди лікування не показує**.

Не казати як факт:

- що додаток веде «тиск на рану» / сортування / лікування для цивільних (у safe mode — ні);
- SOS-маяк Морзе + ультразвук «як у FEMA App» — у FEMA App цього немає;
- «ми не трекаємо, як SGSecure» — SGSecure якраз бере геолокацію;
- «4 питання як NHS 111» — NHS 111 це великі клінічні скрипти, не наш чек-лист;
- MARCH як ядро для цивільного — у продукті свідомо інший рівень.

Аналогії (Швеція MSB, Home Front, Safety Tips) — лише як натхнення **після** цього списку, і лише для прийнятих фіч. Деталі: `світовий-досвід.md`.
