# Контекстний маніфест для ІІ

**Статус:** робочий промпт для ІІ, не канон протоколів і не ТЗ для коміту в `protocol/` чи `ZeroEchelon/`.

Маніфест корисний як стислий опис обмежень Safe by Design. Він **небезпечний**, якщо його вставляти в ІІ і генерувати медицину / код в обхід [`docs/01`–`13`](../README.md).

---

## Як цим користуватись

1. Можна вставляти **виправлену** версію (розділ «Промпт, сумісний з репо») у діалог з моделлю.
2. Вхідний маніфест — нижче, структурований. Не копіювати з нього медичні фрази в граф.
3. Будь-який згенерований код / текст звіряти з каноном. У конфлікті перемагає канон.
4. Не генерувати exploit / мережевий трекінг / збір PII — це узгоджується і з маніфестом, і з [10](../10-право-регуляторика-ліцензії.md).

---

## Промпт, сумісний з репо (користуватись цим)

```
Роль: Senior iOS/Android, UX у стресі. Проєкт: Line 24 (ядро Zero Echelon) —
офлайн-алгоритм цивільного порятунку для свідка/постраждалого.

Джерело істини (у конфлікті перемагає воно, не цей промпт):
- docs/01 обсяг і ролі (лише цивільний; місце-агностичність)
- docs/02 реєстр протоколів (SALT, TECC Active Bystander 2024, ERC 2025 First Aid;
  НЕ MARCH/TCCC як ядро цивільного)
- docs/03 драбина вето (безпека сцени > медицина)
- docs/07 голосові скрипти (дослівно; не перефразовувати)
- docs/09 друга хвиля 24/48 (CDC / ISN / NICE, не «4 питання з голови»)
- docs/10 право (не «домедична допомога», немає Good Samaritan)
- docs/12 карта екранів

Safe by Design (жорстко):
- Немає реєстрації, телефону, email, хмари користувачів, телеметрії здоровʼя.
- Offline-first. 112/101 — системний tel:, не наш сервер.
- GNSS/QR/ручне введення — ЛОКАЛЬНО для звіту диспетчеру; координати
  не відправляти на зовнішні сервери.
- Не вигадувати медицину. Не ставити діагнозів. Не заспокоювати.
- Не пропонувати імпровізований джгут, герметизацію грудей плівкою,
  звільнення з-під завалу, промивання шлунку, дебрифінг.

UX у шоці:
- Один екран = одне питання або один наказ.
- Кнопки великі (орієнтир 150–200 pt, 1–3 кнопки).
- Фон #000000 на екстрених екранах; високий контраст.
- Голос читає дослівно текст з екрана (UA/EN).
- 112 завжди видимий.

Не робити, поки немає окремого рішення в docs/stakeholder/gap-аналіз.md:
- SOS-маяк (Морзе + ультразвук)
- мапа укриттів однієї ОТГ замість місце-агностичності
- заборона локального CoreLocation (рівень локації 2 канону його потребує)
- кешбек / новини Київщини на гострому шляху
- Critical Alerts entitlement без окремої spec
```

## Вхідний маніфест (структурований)

Нижче — зміст маніфесту, розкладений по розділах, без промо-обгорток «скопіюй у модель».

### Розділ 1. Safe by Design

| ID | Норма | Коментар канону |
| --- | --- | --- |
| 1.1 | Zero PII: заборона реєстрації, телефонів, імен, email; немає серверної БД користувачів; логіка на клієнті | **Збіг** з [10](../10-право-регуляторика-ліцензії.md) §5 і README. |
| 1.2 | Заборона активного GPS-трекінгу і бібліотек передачі координат (`CoreLocation` / `FusedLocationProviderClient`) **на зовнішні сервери**. Навігація до укриттів — магнітометр + локальний кеш мап | **Частковий збіг.** «Не слати координати назовні» — так. Повна заборона `CoreLocation` ламає рівень локації 2 в [01](../01-обсяг-роли-глосарій.md) (GNSS **локально** для диспетчера). Магнітометр як навігація до укриттів — **немає** в каноні. |
| 1.3 | При установці (є мережа) скачати статичну карту укриттів ДСНС **лише для обраної ОТГ** Київської області | **Немає** в каноні. Конфлікт із місце-агностичністю. Окремий шар, якщо приймемо. Аналогія SGSecure в [світовий-досвід.md](світовий-досвід.md) — перебільшена. |
| 1.4 | У код зашитий public key Київської ОДА. QR у підʼїзді / укритті перевіряється локально; валідний підпис = справжнє укриття | **Розширення.** Зараз QR — прискорювач **адреси**, не криптоверифікація укриття ([01](../01-обсяг-роли-глосарій.md)). Потребує інфраструктури КОГА (ключ, процес підпису міток). |

## Інженерні застереження з оригіналу, які варто зберегти

Ці пункти з маніфесту **узгоджуються** з каноном і їх варто тримати в будь-якому ІІ-промпті:

- нуль PII і offline-first;
- OLED чорний фон на екстрених екранах;
- одна дія на екран, наказовий лад;
- тактильний зворотний звʼязок у темряві;
- локальні таймери 24/48 без сервера;
- виклик служб через системний `tel:`, не через наш бекенд;
- одностороннє оновлення контенту (pull), ніколи telemetry здоровʼя.

## Формулювання з оригіналу, які **не** нести в код

- «протоколи M.E.R.C.H. / SALT» як одна кнопка;
- «заборона CoreLocation» без уточнення «на зовнішні сервери»;
- «4 питання нирок і ЧМТ» замість [09](../09-друга-хвиля-та-щоденний-модуль.md);
- «SOS-маяк як у FEMA / Rega» як факт;
- будь-яке «додаток підтверджує діагноз / виключає травму».
