# Gap-аналіз: концепція розширень vs канон Zero Echelon

**Дата:** 17.09.2026.  
**Вхід:** майстер-план + AI-маніфест + реєстр «світовий досвід».  
**Канон:** [`docs/01`–`13`](../README.md), реалізація iOS / web у репозиторії.  
**Правило:** цей файл **не** змінює канон. Зміна канону — окреме рішення зі статусом «прийнято» і правкою по ланцюгу 02 → 03 → 07/12.

Вхідний пакет змішує чотири жанри: стратегію, промпт для ІІ, маркетинг для КОГА/Брюсселя і чернетку фіч. Розділяти їх обовʼязково, інакше в продукт потраплять неперевірені медичні фрази і перебільшені посилання на FEMA/SGSecure.

## 2. Конфлікти — потрібне продуктове рішення

Поки рядок не має статусу «прийнято» або «відхилено», у код і в `01`–`13` не йде.

| ID | Концепція | Канон зараз | Ризик, якщо взяти сліпо | Пропозиція |
| --- | --- | --- | --- | --- |
| D1 | Заборона `CoreLocation` / GPS | Рівень локації 2: GNSS **на пристрої**, показати координати диспетчеру | Втрачаємо найточніший офлайн-канал, коли немає QR | Прийняти норму «не відправляти координати назовні». Залишити локальний GNSS. |
| D2 | Home = 3 кольорові кнопки (пожежа / кровотеча / SOS-маяк) | Home = подія зараз / симптоми / чек-лист після події | Людина в паніці тисне «пожежа» і пропускає роль, локацію, вето сцени, 112 | Не заміняти Home. Кольори — на **гілках** після типу події, не замість карти екранів. SOS — окремий вихід, не третя «медична» кнопка. |
| D3 | Медичне ядро M.E.R.C.H. / SALT на одній кнопці | SALT + TECC Active Bystander; MARCH свідомо не є назвою рівня | Повертаємо помилку, яку [11](../11-пілот-та-валідація.md) §2 уже закрив | Відхилити MARCH як ярлик. SALT лишається. |
| D4 | Навігація до укриттів компасом + кеш мапи однієї ОТГ | Місце-агностичний алгоритм; QR = адреса, не мапа | Додаток «тільки Київщина / одна громада» ламає вагон, трасу, іншу область | Мапа укриттів — **опційний шар після установки**, вимкнений на гострому шляху. Ядро без мапи. |
| D5 | 4 питання: сеча, зіниці, нудота, набряки | [09](../09-друга-хвиля-та-щоденний-модуль.md): легені, живіт, краш, голова (NICE) | Втрата кровохаркання / болю в грудях; «зіниці» як псевдодіагностика ЧМТ | Не заміняти. Можна **скоротити формулювання** канону, не список ознак. |
| D6 | Аудіокоманди строго 3–4 слова | [07](../07-голосові-скрипти-UA-EN.md): наказ + заборона, до ~12 слів | Зникне «не звільняй», «не герметизуй», «не джгут із ременя» | Тримати короткі накази. Не різати заборони. |

Статус усіх D1–D6: **очікує рішення**. Колонка «Пропозиція» — позиція інженерії, не затверджений продуктовий вибір.

Кожен рядок, якщо приймаємо, йде спочатку в `.cursor/specs/`, потім у відповідний `docs/0x`, потім у код.

| ID | Фіча | Блок майстер-плану | Залежності / обмеження |
| --- | --- | --- | --- |
| B1 | Спека шок-UI: 150–200 pt, `#000000`, контрастні маркери, без анімацій | 1 / 2.1 | Не ламати рамку [12](../12-екрани-та-специфікація.md) (завжди 112) |
| B2 | Унікальні патерни вібрації на тип дії | 2.1 | Accessibility: не заміняти голос і текст |
| B3 | Тест кнопок під сирени / паніку | T2 | Розширити [11](../11-пілот-та-валідація.md), не окремий «блок тестів» поза каноном |
| B4 | Замір батареї в холоді; ціль 3–4 %/год лише після цифри | T4 | Non-functional spec; не обіцяти КОГА до заміру |
| B5 | Крипто-QR укриття (public key КОГА) | 1.4 | Потрібні ключ, процес підпису, відкликання міток |
| B6 | Картки виживання: вода, блекаут, пожежа в побуті | C2 / 4.1 | Окремий граф або статті; джерела ДСНС/MSB, не вигадувати |
| B7 | Critical Alerts для 24/48 | 3.1 | iOS entitlement від Apple; Android high-importance channel |
| B8 | SOS-маяк: спалах Морзе (без RF) | T3 / 2.4 | Локально можливо. Не називати «FEMA». Перевірити App Store (камера/строб). |
| B9 | Ультразвук 12–15 кГц «для собак» | T3 / 2.4 | Окреме дослідження: динамік телефону, бетон, слух собак, шкода людям. **Не брати в пілот** без цього. |
| B10 | Одностороння JSON-стрічка КОГА | K1 | Pull only, без ідентифікатора пристрою |
| B11 | Карта маршрутів вихідного дня | K2 | Поза гострим шляхом; ліцензії мап |

B8 можна прототипувати. B9 — ні, поки немає технічного висновку.

## 4. Перебільшення — не нести назовні

Деталі перевірок: [світовий-досвід.md](світовий-досвід.md).

| Твердження з концепції | Чому не можна казати |
| --- | --- |
| «Алгоритми дотягнулись до всього ключового, нічого не упустили» | У каноні свідомо **немає** мап ОТГ, SOS-маяка, кешбеку, гідів Київщини. Це не дірки ядра порятунку — але фраза неправдива. |
| SOS-маяк Морзе + ультразвук «як у FEMA App» | FEMA App цього не робить. |
| Локальне гео-кешування без GPS «як SGSecure» | SGSecure бере location і шле SOS-локацію поліції. |
| Бінарний шок-UI «як Safety Tips / J-Alert» | Safety Tips — пуші й довідкові флоучарти евакуації, не гігантські ТАК/НІ. |
| 4 питання «як NHS 111» | NHS Pathways — великі клінічні скрипти, не 4 питання вибухової хвилі. |

Для Брюсселя / губернатора використовувати абзац з [11](../11-пілот-та-валідація.md) §1 (SALT, TECC, ERC, Stop the Bleed, M/ETHANE, PFA, CDC/ISN/NICE). Шпаргалку країн — лише як другий слайд **натхнення**, після канону.

## 6. Рекомендований порядок роботи

1. Зафіксувати, що ядро блоків 1–2 уже в каноні; нову медицину з маніфесту не генерувати.
2. **Рішення D1–D6** (коротка зустріч). Без цього шок-кнопки і мапи ОТГ розʼїдуть продукт.
3. Якщо потрібен видимий наступний артефакт — **таблиця скорочених голосових фраз** з [07](../07-голосові-скрипти-UA-EN.md) (не нові протоколи) **або** додаток тестів T2/T4 до [11](../11-пілот-та-валідація.md).
4. Backlog B1–B2 (візуал шок-UI + гаптика) — перші spec, які не ламають медицину.
5. Блоки 3–4 (Київщина, кешбек) — партнерський трек, паралельно, поза `protocol/`.
