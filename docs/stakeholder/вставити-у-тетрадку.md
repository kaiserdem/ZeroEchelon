**ВСТАВИТИ:**

### 4.5. Як фіксувати результати

Головне — **не відео «для краси»**, а **однаковий протокол на кожен прогін**. Інакше група потім сперечається спогадами.

#### Основа — форма спостерігача (завжди)

Папір або та сама форма в телефоні спостерігача. **На кожного учасника / кожен прогін — один аркуш.**

Без заповненої форми відео **ніхто не зведе** в таблицю.

Поля аркуша (мінімум):

| Поле | Що писати |
| --- | --- |
| Дата / майданчик (A підʼїзд / B глуха громада) |  |
| № сценарію (1–8) |  |
| Роль | свідок / собі (постраждалий) |
| Мова | UA / EN |
| Час до першої **правильної** дії (сек) | від відкриття додатка |
| Чи пішов до мовчазного раніше за кричущого | так / ні / н.д. (лише сц. 2) |
| Чи натиснув / викликав **112** (або **101** у сц. 5) | так / ні |
| Фатальні / заборонені дії | заклеїв груди · ремінь-джгут · поліз у завал · «звільнив» · ігнорував UXO · дебрифінг |
| Чи закрив додаток / «я сам знаю» | так / ні |
| Чи зачитав місце диспетчеру (свого рівня точності) | так / ні / частково |
| Зупинка спостерігача | так / ні · що саме збирався зробити |
| Примітка (1 рядок) |  |

Спостерігач **не підказує**, доки не спрацює критерій зупинки (завал, груди, ремінь, звільнення, UXO).

#### Відео — додаток, не заміна форми

- Знімаємо **екран телефону + руки**, не обличчя — якщо людина не дала **окремої** згоди на обличчя.
- Навіщо: перевірити час і чи справді була фатальна помилка. Сирена, темрява, «я сам знаю» на відео видно краще, ніж у звіті.
- Відео без заповненої форми **не** є офіційним результатом.

#### Фото — рідко

- Один кадр екрана в кінці (звіт для служб / QR).
- За потреби — майданчик «до / після».
- Фото облич і муляжів «як було страшно» для міжвідомчої групи **не потрібні**.

#### Що класти в офіційний результат

1. **Зведена таблиця** по сценаріях (усі прогони з форм).
2. **1–2 анонімні кліпи** лише там, де була помилка або яскравий успіх.
3. **Рішення групи:** що змінити в тексті екрана / голосі.

Це **додаток до технічного docs/11**, не презентація з іменами учасників.

#### До старту кола 2 (підписати)

Психолог і юрист бачать це **до** сирени, не після:

- згода на зйомку; окремо: **обличчя так / ні**;
- хто зберігає файли;
- термін видалення;
- заборона викладати в соцмережі.

**Коротко:** форма спостерігача завжди; відео рук і екрана за згодою; фото майже не треба.
