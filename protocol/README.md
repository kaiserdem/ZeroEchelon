# protocol/

Єдине **ядро алгоритму** для iOS і web. Тут лежать дані (граф рішень, тексти UA/EN, версія), не UI.

## Призначення

- Описати кожен екран/крок як вузол: текст, кнопки, куди йти далі.
- Тримати `commercial: false` і посилання на записи реєстру з `docs/02`.
- Бути офлайн-пакетом: клієнт качає або вшиває цей каталог і працює без мережі.

## Каталоги

| Шлях | Що буде |
| --- | --- |
| `schema/` | JSON Schema формату вузла (за docs/06) |
| `graphs/zero-echelon-core/` | `manifest.json` + вузли графа |
| `locales/` | винесені рядки uk/en, якщо не вшиті в вузли |
| `fixtures/` | короткі сценарії для автоперевірки рушія |

## Правила

1. Жодної логіки «якщо кровотеча» у Swift чи TypeScript поза читанням цього графа.
2. Зміна тексту спочатку в `docs/07`, потім сюди.
3. Вузли зі спірними рішеннями медика можна позначити `"status": "draft"` у метаданих.

Код клієнтів цей каталог лише **читає**.
